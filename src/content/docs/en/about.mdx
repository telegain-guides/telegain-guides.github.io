## What this is

A public knowledge base for working with the TeleGain panel. It answers the question “how do I do
this”: the order of actions, what each interface field is for, a safe test run and how to read
the result.

Module overviews and product information live on the
[official site](https://telegain.net/en/modules).

## How it is maintained

Every page carries a last-checked date. Screenshots are taken from the panel interface on
demonstration data and updated when the interface changes.

Found something inaccurate?
[Open an issue](https://github.com/telegain-guides/telegain-guides.github.io/issues).
